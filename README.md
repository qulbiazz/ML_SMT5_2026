## Cara membaca isi folder

- Berkas bernama `Praktikum...` adalah pengerjaan kegiatan praktikum.
- Berkas bernama `Tugas...` atau `TG...` adalah pengerjaan tugas.
- Notebook dan berkas aplikasi terkait disimpan bersama dalam folder jobsheet masing-masing.
- Dataset CSV disimpan di [data/tabular/](data/tabular/).
- Dataset gambar disimpan terpisah di [data/images/](data/images/), dikelompokkan menurut jenis tugas.
- Gambar pendukung non-dataset disimpan di [assets/](assets/).

Untuk menjalankan aplikasi PBL Jobsheet 15, lihat petunjuk di [README PBL Jobsheet 15](praktikum/pbl/jobsheet-15/README.md).
